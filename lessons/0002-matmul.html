Умножение матриц — таблица скалярных произведений

В трансформере нет ничего, кроме умножений таких таблиц, сложений и softmax. Научишься читать одну клетку результата — и формулы внимания из урока 3 превратятся в простыни чисел, которые ты считал руками.

что уносишь с урока

Считаешь v·w и клетку C[i][j] в A@B · проверяешь формы (m×k)@(k×n) · понимаешь, зачем в Q@Kᵀ транспонирование.

1. Скалярное произведение: два вектора → одно число

Это та самая мера, что дала «а»·«я» = +0.37 в уроке 1. Два вектора по 3 числа: перемножаем поэлементно, складываем — одно число. Совпали знаки в тех же местах → большое положительное, перепутались → отрицательное:

a = [0.9, 0.1, 0.3] b = [0.8, 0.2, 0.5] a·b = 0.9·0.8 + 0.1·0.2 + 0.3·0.5 = 0.89 ← совпали

a·b = 0.89Подвигай ползунки: одинаковые знаки в одинаковых местах тянут вверх, разные — вниз. Каждая клетка внимания считается этой же мерой.

2. Вектор × матрица: по одному произведению на столбец

Возьмём букву «к» из урока 1 — её вектор из 3 чисел (в бою 256) — и матрицу W[3×2]. Умножение x @ W даёт два числа, и каждое — скалярное произведение x со столбцом W:

x = [0.9, 0.1, 0.3] ← буква «к» w₁ = [0.8, 0.1, 0.3] (столбец 1) x·w₁ = 0.72 + 0.01 + 0.09 = 0.82 w₂ = [−0.2, 0.5, 0.6] (столбец 2) x·w₂ = −0.18 + 0.05 + 0.18 = 0.05 x @ W = [0.82, 0.05] ← новое описание «к» в двух числах

Столбец — это рецепт взвешивания: «умножь первую координату на 0.8, вторую на 0.1, третью на 0.3 и сложи». На языке кода: result = W.T.map(col => dot(x, col)). Если W обучаемая, модель сама выучивает рецепты, которые ей полезны.

3. Матрица × матрица: та же операция, строка за строкой

Теперь слева не одна буква, а три — «к», «а», «к». Каждая строка результата считается как в §2, независимо от соседних. Клетка C[i][j] = скалярное произведение строки i матрицы A и столбца j матрицы B. Тыкай в клетки результата — подсветится, что именно перемножилось:

Правило форм — как контракт типов: (m×k) @ (k×n) → (m×n), внутренние размеры обязаны совпасть, иначе ошибка размерности (попробуй скормить PyTorch (3×3) @ (2×3) — откажется). Верхний индекс ᵀ — транспонирование: строки становятся столбцами. Оно нужно, когда перемножать надо строку со строкой: Q@Kᵀ — это строки Q против строк K, просто K лежит на боку.

4. Зачем это трансформеру

Всё внимание из урока 3 — четыре строчки таких умножений на нашей строке «Привет, как дела?» (17 букв, d=256):

Q = X @ Wq 17×256 @ 256×256 → 17×256 «что ищу» K = X @ Wk 17×256 @ 256×256 → 17×256 «кем являюсь» V = X @ Wv 17×256 @ 256×256 → 17×256 «что отдам» S = Q @ Kᵀ 17×256 @ 256×17 → 17×17 все 289 пар букв разом

Заметь: S[17×17] — таблица «каждая буква × каждая буква», посчитанная одним умножением, без единого цикла. Никакого процесса «кто у кого спрашивает» — GPU просто перемножает таблицы. Wq, Wk, Wv — обучаемые таблицы 256×256; какие «рецепты» в них выучатся, таким и будет внимание. Как читать клетки S — урок 3.
