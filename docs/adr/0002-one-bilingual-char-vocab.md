# Одна двуязычная модель с char-vocab

Рассматривались: byte-level vocab (256 токенов, без токенизатора), две
моноязычные модели (RU/EN), одна двуязычная с char-vocab.

Byte-level отвергнут фактом: кириллица в UTF-8 двухбайтовая, и предсказание
следующего байта после кириллической буквы даёт «какая-то буква идёт», но не
«какая» — свечку-топ-3 из этого не собрать. Две модели отвергнуты: вдвое
артефактов, свитч по алфавиту, смешанный текст рвёт контекст.

Решено: одна двуязычная модель, char-vocab (~120 токенов: латиница +
кириллица + цифры + пунктуация + пробел), EN+RU миксом в претрейне. Разделение
языков возникает в весах само, как у больших multilingual LLM. Для свечки
русского текста кириллическая буква переводится в физическую клавишу через
ЙЦУКЕН↔QWERTY.
