# Стек обучения и рантайма: PyTorch → ONNX → node

Рассматривались: MLX (нативен для Apple Silicon, чуть быстрее) с python-сайдкаром
для инференса, и PyTorch с экспортом в ONNX + `onnxruntime-node` прямо в
predict.cjs.

Решено: PyTorch. На модели ~2-3M параметров преимущество MLX в скорости ничего
не решает (обучение — минуты, инференс <1мс и на ONNX), а цель проекта — понять
практики современных LLM, весь мир которых на PyTorch: выученный train-скрипт
узнаваем в любом индустриальном репо. Рантайм остаётся чистым node-стеком
(keytap → node → HID), python живёт только на этапе обучения.
