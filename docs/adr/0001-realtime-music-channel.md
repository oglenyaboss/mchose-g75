# Реалтайм через музыкальный канал, а не DIY

У прошивки gen-1 (Sino Wealth 8051) два канала покраски клавиш: DIY-таблица
(команда 0x06) и музыкальный оверлей (0x08). DIY обрабатывается синхронно в
главном цикле — при открытой сессии печать получает плавающую латентность,
рука чувствует, счётчики нет. Музыкальный канал кладёт кадры в оверлей-буфер
без блокировки опроса матрицы: 25fps без лагов ввода.

Решено: весь реалтайм (риппл, предикт, ghost-word) идёт только через 0x08 при
lightMode 11. DIY оставлен для разовых операций.
