# Always-on коллектор нажатий

Коллектор нажатий — по сути кейлоггер, и это решение о приватностной позе
проекта. Рассматривались: явные сессии записи (включил/выключил) и always-on
демон. Пользователь выбрал always-on: не хочет вручную включать каждый раз.

Решено: демон под launchd (старт при логине, рестарт при падении), лог —
локальный текстовый файл в .gitignore. Гигиена: скраббинг серий цифр в `<num>`
(карты/телефоны), Cmd-комбинации не пишутся, глобальная пауза-хоткей для
чувствительных сессий. Парольные поля частично прикрыты самим macOS (Secure
Input глушит CGEvent tap). Файл остаётся секретом уровня «всё, что ты печатаешь».
