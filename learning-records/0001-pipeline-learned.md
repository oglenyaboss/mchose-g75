# Конвейер GPT усвоен

Пройден урок 0001 (токен → embedding+позиции → слои → проекция → softmax) — и по пересказу видно усвоение сути: «это всё вероятности, модели просто предсказывают следующий токен, веса — обучаемые числа». Новичком самостоятельно сформулировано, что GPT = Generative Pre-trained Transformer.

**Evidence:** после чтения урока без повторного объяснения связал демку (17×256, softmax 14.6%) с задачей подсветки клавиш; вопросы возникли только на следующей теме (внимание).

**Implications:** можно строить сверху: внимание, обучение, лосс-кривые. База «таблицы чисел и умножения» принята как рабочая ментальная модель.
